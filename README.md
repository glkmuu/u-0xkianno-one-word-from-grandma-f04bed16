The single word grandma would text about AI: knowitall — the fond, slightly scolding label for a machine that knows everything.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes exactly one word, `knowitall`, to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It uses only the Python standard library, needs no network, and is fully deterministic: every run writes the same bytes.
